📊 Dangote Cement Equity Research & Valuation Model
Project Overview
This project is an Excel-based equity research and valuation model developed to assess the financial performance and estimated intrinsic value of Dangote Cement Plc.

The model combines historical financial analysis, five-year financial forecasting, Discounted Cash Flow (DCF) valuation, comparable company analysis and sensitivity testing to develop a structured investment view.

The project was created to demonstrate practical skills relevant to equity research, investment management and financial analysis.

🎯 Project Objectives
The analysis aims to answer four key questions:

How has Dangote Cement performed financially?
What could the company's financial performance look like over the next five years?
What is the estimated intrinsic value of the company's shares?
How does the valuation compare with selected Nigerian cement companies?
📁 Workbook Structure
1. Company Overview
Provides an overview of the business and identifies major investment drivers, catalysts and risks.

2. Historical Financials
Analyses historical financial performance including:

Revenue
EBITDA
Net income
Operating cash flow
Capital expenditure
Debt and equity
Key ratios include revenue growth, EBITDA margin, net profit margin, ROA, ROE, debt-to-equity and interest coverage.

3. Forecast Assumptions
Contains the key assumptions supporting the financial forecast, including:

Revenue growth
EBITDA margin
Tax rate
Capital expenditure
Working capital
Terminal growth
Cost of capital
4. Financial Forecast
Develops a five-year forecast of revenue, EBITDA, EBIT, NOPAT and unlevered free cash flow.

5. DCF Valuation
Estimates intrinsic equity value using the Discounted Cash Flow methodology.

The model includes:

Cost of equity
Cost of debt
WACC
Free cash flow discounting
Terminal value
Enterprise value
Equity value
Implied value per share
6. Sensitivity Analysis
Tests how the estimated share value changes under different WACC and terminal growth assumptions.

7. Comparable Company Analysis
Provides a relative valuation comparison using Nigerian cement companies and key valuation multiples including:

EV/EBITDA
P/E
Enterprise value
Market capitalisation
8. Investment Dashboard
Summarises the major findings of the analysis, including:

Implied value per share
Reference share price
Valuation upside/downside
Investment recommendation
Historical financial performance
Profitability trends
Key risks and catalysts

💡 Key Takeaway
The project demonstrates how company fundamentals, financial forecasts and valuation techniques can be combined to translate financial information into a structured investment thesis.

Rather than relying on a single valuation output, the model considers financial performance, valuation sensitivity, peer multiples, risks and potential catalysts when forming an investment view.

⚠️ Disclaimer
This project was developed for educational and portfolio demonstration purposes only and should not be considered investment advice.

Certain inputs within the model are illustrative assumptions and are clearly identified within the workbook. They should not be interpreted as audited or independently verified financial information.
